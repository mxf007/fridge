# 开工步骤（一次只做一步）

对 AI 说：**只做步骤 N**。做完停，等你点过验收再开下一步。不要一次做完本文件。

源：`docs/今晚冰箱_玩法文档.md` §13。关卡 JSON 只从 §5.4 抄，不要发明关。

| 步 | 做什么 | 验收（不过就停） | 不要做 |
|----|--------|------------------|--------|
| 0 | 编辑器建 `GameScene`，Canvas 720×1280，设初始场景 | 预览是竖屏空画布 | 主页、广告、30 关 |
| 1 | 纯 TS `BoardState` + 第 **1** 关 JSON；场景只绑点击 | 默认已选格；点栈顶 4 次封格；**没有柜台** | 第 2 关、撤销、提示、飞行动画可以先瞬移 |
| 2 | 载入第 **4** 关：两格、迷你换格 | 格 0 未满时点青菜 **弹回**；点格 1 后再放进去 | 第 5–30 关、柜台 |
| 3 | 载入第 **7** 关（试金石） | 不点第二格，青菜永远进不去 | 铺关卡表 |
| 4 | 手填 2、3、5、6、8、9 JSON + `assertLevel` | 件数=容量；能切关玩 | 12–30（表内 24、27 有误） |
| 5 | 求解器 `hasSolution`；第 10、11 关 JSON | 1–11 都能解；第 10 关打 `minBufferUsed` 日志 | 不要把第 10 关写成「不用柜台必败」 |
| 6 | 手感：飞入 220ms、封格盖、分因 Toast、选中描边 | 弹回有原因句 + 闪合法格 | 主页精致图 |
| 7 | 第 10 关亮柜台；撤销 3 次 | 1–9 仍无柜台 | 失败广告 SDK |
| 8 | 主页 / 胜利 / 暂停；提示钮（第 7 关免费） | 1–6 无提示钮 | 图鉴可以后做 |
| 9 | 再谈 12–20（先改第 24、27 关表） | 混容量 17–18 可失败 | 一次生成 30 个 JSON |

**前三关策略：** 只做 1、4、7。第 2、3、5 关是热身，不验证新规则，不必先做。
