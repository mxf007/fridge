# 今晚冰箱 · UI / 视觉设计规格

配套玩法：`docs/今晚冰箱_玩法文档.md`  
效果图：`docs/ui_refs/`（01 风格板 … 12 组件表）

效果图用来定气质。**实现以本文数字和禁令为准**，不要把 AI 图里多出来的计时器、星星、底栏抄进工程。

**与玩法同步：** 对局有「当前目标格」。先点冰箱格（第 10 关起也可点柜台空位），再点食材落入该格。不是自动找格。第 1–9 关不画柜台。

---

## 1. 风格是什么

**风格名：Night Fridge（暖夜厨房）**

一句话：晚上打开冰箱时，冷白光打在黏土食材上，周围是暖木厨房。安静、好点、不像小游戏广告。

参考气质（不要抄界面）：无印良品的厨房收纳、日系黏土静物、Apple Arcade 休闲的留白。  
明确对标并避开：拧螺丝 / 羊了个羊的描边卡通、金币条、倒计时、厚倒角金按钮。

| 要 | 不要 |
|----|------|
| 奶油底 + 冰箱冷光 | 霓虹、炫光描边 |
| 哑光黏土食材 | 写实照片菜、Q 版描边小人 |
| 一个珊瑚色主按钮 | 满屏按钮、每角一个功能 |
| 大留白、大热区 | 资源条、体力心、倒计时 |
| 失败时柜台闪暖红 | 爆炸、嘲笑角色、强制分享墙 |

玩家应在 0.5 秒内读出三件事：这是厨房、东西能点、主按钮在底下。

## 3. 字体与层级

微信小游戏用系统圆体即可，不要嵌入花哨字体。

| 角色 | 字号 @720宽 | 字重 | 色 |
|------|-------------|------|----|
| 主标题 | 56–64 | Medium | Walnut |
| 关卡号 | 28 | Medium | Walnut |
| 正文 | 28 | Regular | Ink |
| 主按钮 | 32 | Medium | Milk |
| 辅助 | 24 | Regular | Walnut 70% |

行高 1.3。按钮字不要加描边、不要斜体。

## 4. 画布与安全区

- 设计稿：**720 × 1280**，竖屏，锚点中间缩放。
- 微信顶栏 + 刘海：内容从 **y = 96** 开始。
- 底手势条：主按钮下沿距底 **≥ 48**。
- 网格：8px。热区最小 **88 × 88**（撤销/提示圆钮外径 80，透明热区拉到 88）。
- 圆角：卡片 32、主按钮胶囊 999、格子 20、圆钮 40。

## 5. 组件（只做这些）

**主按钮**  
高 96、左右边距 48、底 Coral、字 Milk。按下：缩放 0.97，不要换色闪白。全屏同时只允许一个 Coral 按钮。

**次按钮**  
同高，描边 2px Walnut 20%，底透明/Milk。用于「让好友也收这一层」「分享步数」。

**文字链**  
用于「重开本关」。字号 26，Walnut 60%。不要做成第三颗大按钮。

**圆钮（撤销 / 提示）**  
直径 80，底 Milk，浅阴影。撤销 = 回箭头；提示 = 灯泡。用完 3 次撤销后，按钮右上加极小「广告」点，不要换成长条广告位。

**冰箱格**  
对照 `03_play_l1.png`：窄高竖槽，胡桃木圆角框，内壁 FridgeGlow。空格冷光；放入食材后光收弱。收满后**该格的门合上**（灰门填满框内，右侧小把手），不是珊瑚餐盒盖。主页才是整台打开的精致冰箱。容量用叠放件数表达，不要在格上写 2/4。

**选中态（必须一眼可读）**  
当前目标格：2px Walnut 描边 + 槽内冷光加强。未选中格描边关闭。切换选中 80ms 内完成，不要闪全屏。柜台空位被选为当前目标时用同一套描边。

**购物袋**  
一列 = 一叠方砖，只有栈顶亮度 100%，下面 60% 并微缩，表达「点不到」。不要做成写实塑料袋。

**柜台格**  
第 10 关起才出现：胡桃木底盘 + 3 个 Milk 方槽。第 1–9 关购物袋下方留白或只留 Cream 底，不要放三个空盘。失败时：`buffer_full` 槽底 Coral 发光；`locked_out` 改为闪锁死的冰箱格。不要霓虹灯管。

## 6. 界面结构（按效果图落地）

### 6.1 主页 `02_home.png`

上 70% 是打开的冰箱场景（冷光 + 暖厨房），下 30% 是奶油底栏。

- 标题：今晚冰箱
- 副标题：把食材收回该在的格子
- 主按钮：开始收拾 → 进入「已通最高关 + 1」
- 文字链：我收过的冰箱 12/30 → 图鉴
- 右上：设置（音效/震动），不要商城

主页冰箱可以比局内更精致，它是分享缩略图和广告素材的主视觉。局内冰箱改用「四格冷光槽」，保证可点、可读。

### 6.2 对局 `03_play.png`

从上到下三层，中间不能穿插广告条。

```
y 96    第 N 关          [撤销] [提示]
y 180   冰箱槽 2–5 个（横向）
y 560   购物袋 2–6 列
y 980   柜台 3 格（第 10 关起；1–9 关此带留白）
y 1180  柜台 0/3（第 10 关起）
```

- 无倒计时、无金币、无暂停金钮。暂停放进左上关卡号的点击（点关卡号出：重开 / 回主页）。
- 撤销、提示只用图标，中文，不要 Undo/Hint 英文。提示第 7 关起出现。
- 冰箱格可点：点了只换目标，食材不飞。第 10 关起柜台空位同样。
- 提示：同时高亮 **目标格** 和 **该点的食材**，只闪其中一个不够。
- 食材飞入：0.22s 缓出，落格轻震。弹回：横摆 80ms + 分因 Toast 1.2s，并闪可放的格。

### 6.3 胜利 `04_win.png`

对局压暗 40%。中间奶油卡片。

- 标题：今晚的冰箱收好了
- 大数字：18 步（Coral）
- 主按钮：下一关
- 次按钮：分享步数（仅 15/25/30 关强调；其它关可弱化）
- 小章：图鉴 +1
- **不要底导航。** 效果图底部三个图标是生成多余物，删除。
- 卡片顶部可用一张「封好的冰箱」成品图，作为图鉴缩略图来源。

### 6.4 失败 `05_fail.png`

对局仍可见。卡片不要挡死出错的那一层——玩家必须看见失败原因。

**`buffer_full`**
- 标题：柜台堆满了
- 说明：看一段广告，本关多一格继玩
- 主按钮：多一格继玩（激励视频）
- 柜台三格全亮 Coral

**`locked_out`**
- 标题：这格锁错了
- 说明：看一段广告，退回到还能收的一步
- 主按钮：退回可收的一步（激励视频）
- 闪锁死的冰箱格，不要假装是柜台满了

共用：
- 次按钮：让好友也收这一层（拉新，进的是同一关开局）
- 文字链：重开本关（免费）
- **不要星星、倒计时、第 12-3 关。**

### 6.5 图鉴 `06_album.png`

- 标题：我收过的冰箱；右上完成度 `12/30`
- 3 列网格：已解锁为封格冰箱缩略图；未解锁灰剪影 + 锁
- 左上返回。点已解锁缩略图可全屏看成品，不要进商店
- **不要做** 效果图里的「相册」Tab、底栏「开始游戏」

### 6.6 暂停 `07_pause.png`

点关卡号弹出。对局压暗 40%。

- 主按钮：继续收拾（关卡片）
- 次按钮：重开本关
- 文字链：回主页
- 卡片右上可有关闭。不要音量条、不要放弃确认连环弹窗

### 6.7 换格教学 `08_select.png`

第 4、7 关：左格选中（Walnut 描边 + 冷光），右格未选中。栈顶青菜弹回。Toast「换一格」1.2s，并闪右格。防拆分第一次用完整句「牛奶那格还没收满，不能新开一格」。

### 6.8 提示 `09_hint.png`

同时高亮：目标冰箱格 + 该点的食材（Sage 虚线圈）。不要「剩余提示 3/3」计数器。第 7 关第一次点提示不播广告。

### 6.9 设置 `10_settings.png`

只有两行：音效、震动。默认开。  
**不要做** 效果图里的音乐、语言、账号。

### 6.10 分享卡 `11_share.png`

16:9。用主页冰箱精致图 +「今晚的冰箱收好了 / N 步 / 第 N 关」。不要对局槽位截图。失败拉新卡标题「第 N 关这层我收不进去了」，不要写成代打求助。

## 7. 动效（少，但要准）

| 事件 | 时长 | 做什么 |
|------|------|--------|
| 食材飞入 | 220ms | 从点处飞到格，缩放 1.0→1.05→1.0 |
| 封格 | 280ms | 该格灰门合上 + 短震动 |
| 胜利 | 门合上后 | 格轻震 → 压暗 40% → 奶油卡升起 340ms → Coral 步数弹出 →「图鉴 +1」弹出。不要烟花、金币雨、底导航 |
| 无效点 | 80ms + Toast 1.2s | 栈顶横摆；分因文案；闪合法格。不弹模态 |
| 失败前 | 400ms | 柜台闪 Coral 两下，再出卡片 |
| 主按钮按压 | 80ms | scale 0.97 |

不要全屏烟花、不要金币雨。

## 8. 微信适配

- 刘海用 `wx.getWindowInfo().safeArea`，顶栏不要写死 96 到刘海机。
- 分享图用主页冰箱或胜利成品图，不要用对局 UI 截图（槽位太抽象，卡片不吸引）。
- 激励视频按钮文案必须写清收益：「多一格继玩」或「退回可收的一步」，禁止只写「看视频」。

## 9. 美术生产顺序

1. 先做 6 个黏土食材 icon（正视，透明底，256px）。
2. 冰箱槽、柜台槽、盖子三件套。
3. 主页冰箱场景（可先静态图）。
4. 按钮与圆钮。
5. 最后才做封格成品拼贴。

原型期允许用色块代替黏土，但 **色值和三层布局不能改**。改了就不是这个产品。
