# 合成小游戏资源平替清单

## 移植边界

仅保留王之宝藏 `wzbz_xyx_game` 的“移动投放、物理下落、同级合成、计分、越线结束”玩法。

不迁移以下内容：

- `wzbz_xyx` 开始页、礼包、扫荡、排行榜与排行奖励
- `GameData.wzbzData`、`huodongUse`、活动次数与活动货币
- `UIManager`、`UILogic`、红点、国际化和公共弹窗
- Socket、登录、支付、广告、埋点、奖励发放
- 王之宝藏图片、Spine、字体和音频

## 目录约定

- UI：`assets/resources/merge/ui/`
- 音效：`assets/resources/merge/audio/`
- 逻辑：`assets/scripts/merge/`
- 存档：`fridge_merge_best_score`

| 文件 | 建议尺寸 | 用途 |

| `merge_bg.png` | 720×1280 | 独立玩法背景，可延续厨房墙面 |

## 音效规格

不使用 BGM。当前已放入 `assets/resources/merge/audio/`：

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| `merge_click.mp3` | 今晚冰箱 `CLICK_BTN` | 返回、重开 |
| `merge_drop.mp3` | 今晚冰箱 `game_df` | 食材落下 |
| `merge_pop.mp3` | 王之宝藏 `boom` | 同级合成 |
| `merge_game_over.mp3` | 今晚冰箱 `game_failed` | 容器装满 |

后续换肤时保持同名覆盖即可。建议最终仍用原创短音效，时长约：click 0.05–0.12s、drop 0.08–0.18s、pop 0.15–0.30s、game_over 0.4–0.8s。

## 替换步骤

1. 按上表完成原创资源并放入独立目录。
2. 按固定文件名放入或覆盖资源；Creator 导入后会由 `resources` 固定路径自动加载，无需修改玩法代码。
3. 食材图片只替换显示，不改变 `MERGE_FRUITS` 中的碰撞半径。
4. 依次验证首页入口、连续投放、连锁合成、最高分存档、越线结束、返回主页。
