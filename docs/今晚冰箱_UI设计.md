# 今晚冰箱 · UI / 视觉设计规格

配套玩法：`docs/今晚冰箱_玩法文档.md`  
效果图：`docs/ui_refs/`（01 风格板 … 12 组件表）

效果图用来定气质。**实现以本文数字和禁令为准**，不要把 AI 图里多出来的计时器、星星、底栏抄进工程。

**与玩法同步：** 对局有「当前目标格」。先点冰箱格（第 10 关起也可点柜台空位），再点食材落入该格。不是自动找格。第 1–9 关不画柜台。

**2026-09-21 重设计锁定：** 对局采用 **2.5D 精灵场景**，不引入真实 3D 模型。购物袋只显示每列栈顶种类，下层匿名；第 10 关起柜台用于暂存并翻开下一层。下文的空间、状态与坐标规格优先于旧效果图。

## 1. 风格是什么

**风格名：Night Fridge（2.5D 暖夜厨房）**

一句话：玩家从轻俯视角看一张真实有前后关系的厨房工作台——暖墙在远处，冷光冰箱立在中景，购物袋落在台面，胡桃柜台压在前景。

参考气质（不要抄界面）：无印良品的厨房收纳、日系黏土静物、Apple Arcade 休闲的留白。  
明确对标并避开：拧螺丝 / 羊了个羊的描边卡通、金币条、倒计时、厚倒角金按钮。

立体感只来自五件事：**统一视角、可见顶面、前立面、遮挡、同方向投影**。禁止用多重粗描边、霓虹外发光、悬浮胶囊冒充立体。

| 要 | 不要 |
|----|------|
| 奶油底 + 冰箱冷光 | 霓虹、炫光描边 |
| 哑光黏土食材 | 写实照片菜、Q 版描边小人 |
| 一个珊瑚色主按钮 | 满屏按钮、每角一个功能 |
| 大留白、大热区 | 资源条、体力心、倒计时 |
| 失败时柜台闪暖红 | 爆炸、嘲笑角色、强制分享墙 |

玩家应在 0.5 秒内读出四件事：上方是目标冰箱、中间只有栈顶食材可点、下方柜台是暂存区、当前目标格在哪里。

## 4. 画布与安全区

- 设计稿：**720 × 1280**，竖屏，锚点中间缩放。
- 微信顶栏 + 刘海：内容从 **y = 96** 开始。
- 底手势条：主按钮下沿距底 **≥ 48**。
- 网格：8px。热区最小 **88 × 88**（撤销/提示圆钮外径 80，透明热区拉到 88）。
- 圆角：卡片 32、主按钮胶囊 999、格子 20、圆钮 40。

### 4.1 坐标约定

本文布局数字统一使用**屏幕左上为原点**：X 向右、Y 向下。Cocos 对局根节点若以画布中心为原点，换算为：

```text
cocosX = screenX - 360
cocosY = 640 - screenY
```

不要再把屏幕 Y 与 Cocos Y 混写。安全区变化只移动 HUD；冰箱、台面与柜台按 720×1280 设计区整体缩放。

### 4.2 统一 2.5D 造型规范

- 视角：轻俯视三分之四视角；同类物体顶面可见高度约本体高度的 8%–14%。
- 主光：左上暖光；投影统一向右下偏 8–16px，透明度 12%–22%。
- 冰箱辅光：只在内腔出现冷白光，不给整机加蓝色外发光。
- 前立面：台面/柜台前沿高度为顶面厚度的 2–3 倍；越靠前，对比和投影越强。
- 接触阴影：食材与托盘、托盘与台面、冰箱与墙面都必须有短而深的接触影，避免漂浮。
- 背景：饱和度和对比度均低于可交互物；砧板、杯子、绿植只露边，不跨入点击热区。
- 遮挡顺序固定：背景墙 → 冰箱落影 → 冰箱 → 工作台后沿 → 购物袋 → 工作台前沿 → 柜台落影 → 柜台 → HUD/Toast。
- Graphics 只画简单遮罩、光和状态线；主体优先用带顶面与侧厚度的透明 PNG，避免代码矩形堆出“假 3D”。

## 5. 组件（只做这些）

**主按钮**  
高 96、左右边距 48、底 Coral、字 Milk。按下：缩放 0.97，不要换色闪白。全屏同时只允许一个 Coral 按钮。

**次按钮**  
同高，描边 2px Walnut 20%，底透明/Milk。用于「让好友也收这一层」「分享步数」。

**文字链**  
用于「重开本关」。字号 26，Walnut 60%。不要做成第三颗大按钮。

**圆钮（撤销 / 提示）**  
直径 80，底 Milk，浅阴影。撤销 = 回箭头；提示 = 灯泡。用完 3 次撤销后，按钮右上加极小「广告」点，不要换成长条广告位。

**冰箱格**  
局内也必须先读成“一台冰箱”，再读成若干槽位。整机是共享的灰蓝软壳：带窄顶面、左右侧厚度和墙面落影；槽位是壳体挖出的内窗，不是一排独立木框。所有槽外高一致，cap2/3/4 通过内腔可用高度、上方壳体填充和底托位置区分，不把小容量槽整体缩短。

内腔从后到前：后壁渐暗 → 顶灯条 → FridgeGlow 可用区 → 底托 → 食材接触影。空格冷光最强；放入食材后收弱。收满后**该槽灰门合上**（带右侧小把手），不是珊瑚餐盒盖。容量靠空间和叠放件数表达，不写 2/4。

**选中态（必须一眼可读）**  
当前目标格同时出现三层轻提示：内腔冷光增强、贴内窗沿的 2–3px Walnut 描边、槽内容物整体向前放大约 1.03。未选中格不画外圈，只把内光降到 70%–80%。切换 80ms 内完成；可做低幅呼吸，但不得整格刷深色、套 8px 珊瑚粗框或添加「放这里」徽章。柜台目标位沿用“内光 + 细窗沿”，形状跟随方槽。

**购物袋**  
一列 = 一叠托盘。只有栈顶显示黏土食材并保持 100% 亮度；下层食材图完全隐藏，只露中性奶油托盘边和层数刻痕。不能通过托盘颜色、半透明食材或轮廓猜出下层种类。列底有接触影，所有列坐在同一工作台顶面。移走栈顶后，下一层 180ms 上浮并显出食材；不要做成写实塑料袋。

**柜台格**  
第 10 关起才出现：厚胡桃木前景板 + 3 个 Milk 凹槽。木板位于工作台前方，遮住一部分台面前沿并投全场最强软影，明确比购物袋更靠近玩家。第 1–9 关只显示完整工作台，不画空盘或虚影。食材放入后坐进凹槽并有接触影；取回时先抬起再飞向冰箱。

### 5.1 玩法状态语言

| 状态 | 唯一视觉语言 | 禁止 |
|------|--------------|------|
| 可点栈顶 | 完整食材、正常饱和度、短接触影 | 外围常驻发光 |
| 未知下层 | 中性托盘边 + 层数刻痕 | 泄露食材颜色/轮廓 |
| 当前目标 | 冷光增强 + Walnut 细窗沿 + 1.03 前移 | 珊瑚粗框、文字徽章 |
| 可收但未选 | 原亮度；提示时才闪 Sage | 常驻描边抢层级 |
| 柜台暂存 | 食材坐入前景凹槽，下一层上浮 | 自动进入柜台 |
| 容量危险 | 相关冰箱内腔短闪 Coral 两次 | 全屏红、提前弹失败 |
| 提示 | Sage 虚线同时圈目标与该点食材 | 只圈其中一个 |
| `buffer_full` | 柜台槽底 Coral 闪；仅用于 +1 格可救 | 锁错也闪柜台 |
| `locked_out` | 锁错冰箱槽内 Coral 闪 | 假装柜台满 |

## 6. 界面结构（按 2.5D 空间落地）

### 6.1 主页 `02_home.png`

上 70% 是打开的冰箱场景（冷光 + 暖厨房），下 30% 是奶油底栏。

- 标题：今晚冰箱
- 副标题：把食材收回该在的格子
- 主按钮：开始收拾 → 进入「已通最高关 + 1」
- 文字链：我收过的冰箱 12/30 → 图鉴
- 右上：设置（音效/震动），不要商城

主页与局内使用同一透视和光向。主页冰箱可以更精致，它是分享缩略图和广告素材主视觉；局内根据关卡显示 1–5 个内窗，但始终保留完整壳体、顶面与两侧厚度。

### 6.2 对局 `03_play.png`

对局不是三排 UI，而是同一厨房中的四个纵深面。以下为**屏幕左上坐标**：

```
y  88–164    HUD：第 N 关 / 撤销 / 提示
y 178–520    中景冰箱整机（含墙面落影）
y 548–920    工作台顶面 + 购物袋 2–6 列
y 850–960    工作台前立面
y 930–1168   前景柜台板（第 10 关起）
y 1168–1232  柜台 n/3 或安全留白
```

- **远景墙面：** 使用低对比暖墙；左右道具露边，中央保持干净。不要把所有交互物直接贴在背景图上。
- **中景冰箱：** 宽度随槽数变化但不超过 648；单槽关也保留至少 260 宽的壳体“耳朵”。底部投影落向工作台后方。
- **工作面：** 顶面形成清楚梯形/圆角平面，购物袋底部与台面有接触影。前立面遮住袋子最底层一小部分，建立“坐在台上”的关系，但不得遮挡栈顶热区。
- **前景柜台：** 第 10 关起覆盖工作台前沿的一部分；其顶面和槽位比购物袋更大、对比更强。第 1–9 关完全不实例化柜台节点。
- 无倒计时、无金币、无暂停金钮。暂停放进左上关卡号的点击（点关卡号出：重开 / 回主页）。
- 撤销、提示只用图标，中文，不要 Undo/Hint 英文。提示第 7 关起出现。
- 冰箱格可点：点了只换目标，食材不飞。第 10 关起柜台空位同样。
- 提示：同时高亮 **目标格** 和 **该点的食材**，只闪其中一个不够。
- 食材飞入：沿轻微上拱弧线 0.22s 缓出，跨层时始终盖在台面、低于 HUD；落格轻震。弹回：横摆 80ms + 分因 Toast 1.2s，并闪可放的格。
- 移走栈顶后，下层先上浮 8–12px，再从匿名托盘切换为真实食材，总时长 180ms；切换完成前该列不可重复点击。

### 6.3 胜利 `04_win.png`

对局压暗 40%。中间奶油卡片。

- 标题：今晚的冰箱收好了
- 大数字：本局 18 步（Coral）
- 次信息：首通时显示「已收进图鉴」；重玩时显示「最佳 16 步 / 目标 18 步」
- 主按钮：下一关
- 次按钮：分享步数（仅 15/25/30 关强调；其它关可弱化）
- 小章：首次为「图鉴 +1」；达到成绩线显示「利落收纳」或「完美收纳」
- **不要底导航。** 效果图底部三个图标是生成多余物，删除。
- 卡片顶部使用同透视的「封好冰箱」2.5D 成品图，作为图鉴缩略图来源。

### 6.4 失败 `05_fail.png`

对局仍可见。卡片不要挡死出错的那一层——玩家必须看见失败原因。

**`buffer_full`**
- 标题：柜台堆满了
- 说明：看一段广告，本关多一格继玩
- 主按钮：多一格继玩（激励视频）
- 柜台三格全亮 Coral

**`locked_out`**
- 标题：这格锁错了
- 说明：看一段广告，退回到还能收的一步
- 主按钮：退回可收的一步（激励视频）
- 闪锁死的冰箱格，不要假装是柜台满了

共用：
- 次按钮：让好友也收这一层（拉新，进的是同一关开局）
- 文字链：重开本关（免费）
- **不要星星、倒计时、第 12-3 关。**

### 6.5 图鉴 `06_album.png`

- 标题：我收过的冰箱；右上完成度 `12/30`
- 3 列网格：已解锁为封格冰箱缩略图，并显示首通步数、个人最佳、最高印章；未解锁灰剪影 + 锁
- 左上返回。点已解锁缩略图先全屏看成品，下方提供「再收一次」；不要进商店
- 重玩 HUD 才可出现小型「最佳 X / 目标 Y」，首通不显示评级压力
- **不要做** 效果图里的「相册」Tab、底栏「开始游戏」

### 6.6 暂停 `07_pause.png`

点关卡号弹出。对局压暗 40%。

- 主按钮：继续收拾（关卡片）
- 次按钮：重开本关
- 文字链：回主页
- 卡片右上可有关闭。不要音量条、不要放弃确认连环弹窗

### 6.7 换格教学 `08_select.png`

第 4、7 关：左格选中（Walnut 描边 + 冷光），右格未选中。栈顶青菜弹回。Toast「换一格」1.2s，并闪右格。防拆分第一次用完整句「牛奶那格还没收满，不能新开一格」。

### 6.8 提示 `09_hint.png`

同时高亮：目标冰箱格 + 该点的食材（Sage 虚线圈）。不要「剩余提示 3/3」计数器。第 7 关第一次点提示不播广告。

### 6.8.1 容量与柜台教学

- **第 8 关容量入门：** cap2/cap4 的整机外框齐高；小格通过上方壳体填充和较浅内腔表达，禁止用数字标签代替空间。
- **第 9 关第一次锁错：** 锁错后只闪相关内腔 Coral，并让玩家看见剩余食材与空余容量的矛盾；不闪不存在的柜台。
- **第 10 关柜台翻层：** 第一次暂存时，镜头不移动。食材落入前景槽，原列下一层上浮显形，柜台槽轻沉 4px，形成清楚的“放下一个、看见下面”因果链。

### 6.9 设置 `10_settings.png`

只有两行：音效、震动。默认开。  
**不要做** 效果图里的音乐、语言、账号。

### 6.10 分享卡 `11_share.png`

16:9。用主页冰箱精致图 +「今晚的冰箱收好了 / N 步 / 第 N 关」。不要对局槽位截图。失败拉新卡标题「第 N 关这层我收不进去了」，不要写成代打求助。

## 7. 动效（少，但要准）

| 事件 | 时长 | 做什么 |
|------|------|--------|
| 食材飞入 | 220ms | 从点处飞到格，缩放 1.0→1.05→1.0 |
| 翻开下层 | 180ms | 匿名托盘上浮 8–12px → 显示食材；该列暂时锁点击 |
| 放入柜台 | 220ms | 食材向前下方飞入凹槽，槽轻沉 4px 后回弹 |
| 封格 | 280ms | 该格灰门合上 + 短震动 |
| 胜利 | 门合上后 | 格轻震 → 压暗 40% → 奶油卡升起 340ms → Coral 步数弹出 →「图鉴 +1」弹出。不要烟花、金币雨、底导航 |
| 无效点 | 80ms + Toast 1.2s | 栈顶横摆；分因文案；闪合法格。不弹模态 |
| 失败前 | 400ms | `buffer_full` 闪柜台；`locked_out` 闪锁错内腔；再出卡片 |
| 主按钮按压 | 80ms | scale 0.97 |

不要全屏烟花、不要金币雨。

## 8. 微信适配

- 刘海用 `wx.getWindowInfo().safeArea`，顶栏不要写死 96 到刘海机。

## 9. 美术生产顺序

1. 先拆远景墙、工作台顶面、工作台前立面和软影，验证四个纵深面。
2. 做共享冰箱壳体、内腔、容量填充和灰门。
3. 补 `bag_hidden` 与翻层遮罩；现有 `bag_*` 只做栈顶。
4. 接前景 `buffer_board` 和柜台槽。
5. 完成目标、提示、危险和失败状态。
6. 最后做主页冰箱、胜利成品、图鉴框与分享卡。

原型期允许用色块代替黏土，但 **色值、四个纵深面和遮挡顺序不能改**。可以简化材质，不得退回“背景图上漂三排组件”。
