# 对局主场景 · 2.5D 空间方案

权威来源：`docs/今晚冰箱_玩法文档.md`、`docs/今晚冰箱_UI设计.md`。
本文只说明对局场景的空间、坐标、遮挡和状态落地，不覆盖玩法规则。

## 1. 目标

静态截图 0.5 秒内必须读出：

1. 上方是一台完整的灰蓝冰箱，不是一排独立盒子。
2. 中间购物袋放在工作台上，只有每列栈顶食材可见、可点。
3. 第 10 关起，胡桃柜台处于最前景，是有限暂存区。
4. 当前目标格靠内腔冷光和细窗沿识别，不靠文字徽章。

采用 2.5D 精灵，不使用真实 3D 模型、透视相机、实时灯光或材质。

## 2. 坐标

设计坐标固定为 720×1280，屏幕左上为 `(0, 0)`，Y 向下。

```text
cocosX = screenX - 360
cocosY = 640 - screenY
```

| 屏幕区间 | 内容 |
|----------|------|
| Y 88–164 | HUD |
| Y 178–520 | 冰箱整机 |
| Y 548–920 | 工作台顶面与购物袋 |
| Y 850–960 | 工作台前立面 |
| Y 930–1168 | 前景柜台（第 10 关起） |
| Y 1168–1232 | 柜台计数或安全留白 |

刘海只影响 HUD 安全偏移。场景主体按 720×1280 整体缩放，不逐节点追刘海。

## 3. 四个纵深面

### 3.1 远景：暖墙

- 低对比奶油墙，砧板、杯子、绿植只露左右边缘。
- 中央不放高对比物，不与冰箱内腔和食材抢视线。
- 背景节点不可响应触摸。

### 3.2 中景：冰箱

- 一整块灰蓝软壳，含窄顶面、左右侧厚度、共享隔断和墙面落影。
- 整机最大宽 648；单槽关也至少 260 宽，保留左右“耳朵”。
- 所有槽外高一致。cap2/3/4 只改变内腔可用高度、上填充和底托位置。
- 内腔顺序：后壁渐暗 → 顶灯 → 可用冷光区 → 底托 → 食材接触影。
- 封格时灰门只盖住该内腔，右侧有小把手。

### 3.3 工作面：购物袋

- 工作台有顶面和前立面，不是悬浮胶囊底座。
- 所有列都坐在同一顶面并有接触影。
- 栈顶使用 `bag_*`；下层统一使用匿名奶油托盘，不显示食材颜色或轮廓。
- 下层只表达剩余层数。移走栈顶后，下一层上浮 8–12px 并在 180ms 内显形。
- 工作台前立面可遮住袋底少量像素，但不能进入栈顶 88×88 热区。

### 3.4 前景：柜台

- 第 10 关起才实例化；第 1–9 关不画空盘、不画虚影。
- 胡桃木板覆盖工作台前沿一部分，投全场最强软影。
- 三个 Milk 凹槽尺寸和透视一致；食材放入后坐进槽内并有接触影。
- 柜台比购物袋对比更强、尺寸略大，明确更靠近玩家。

## 4. 统一立体语言

| 项目 | 规格 |
|------|------|
| 视角 | 轻俯视三分之四视角 |
| 顶面 | 可见高度约物体高度 8%–14% |
| 主光 | 左上暖光 |
| 冰箱辅光 | 只在内腔出现冷白光 |
| 投影 | 向右下 8–16px，透明度 12%–22% |
| 接触影 | 短、深，贴住物体底部 |
| 前后关系 | 越靠前，对比、尺寸、阴影越强 |

禁止多层粗描边、霓虹灯管、整格深色填充、互相冲突的光向。

## 5. 渲染与触摸顺序

```text
背景墙
冰箱墙影
冰箱壳体与内腔
冰箱食材与门
工作台顶面
购物袋下层
购物袋栈顶
工作台前立面
柜台落影
柜台板与食材
飞行食材
HUD / Toast / 弹层
```

- 只有冰箱内窗、购物袋栈顶、柜台槽/食材、HUD 按钮响应触摸。
- 台面、影子、壳体、填充块、层数刻痕不得抢事件。
- 飞行动画跨层时高于场景物件、低于 HUD 和 Toast。

## 6. 关键状态

### 当前目标

- 内腔冷光增强。
- 内窗沿出现 2–3px Walnut 描边。
- 内容整体前移到 scale 1.03。
- 未选中槽不画外框，内光降到 70%–80%。

不要珊瑚粗框、双重呼吸圈或「放这里」文字。

### 隐藏与翻层

- 栈顶完整显示食材。
- 下层只显示匿名托盘和层数，不得泄露种类。
- 暂存/移走栈顶后，匿名托盘上浮再切换为真实食材。
- 翻层完成前锁住该列点击。

### 提示

Sage 虚线同时圈住一个安全目标和一个当前可点食材。只圈一个不合格。

### 危险与失败

- 尚有合法动作：只让相关内腔短闪 Coral，不弹结算。
- `buffer_full`：仅柜台槽底闪 Coral。
- `locked_out`：仅锁错冰箱内腔闪 Coral。
- 禁止全屏红、爆炸或把两类失败画成同一种。

## 7. 固定验收关

| 关 | 看什么 |
|----|--------|
| 1 | 单槽仍像一台冰箱；购物袋落在台面；没有柜台 |
| 8 | cap2/cap4 外框齐高，但内腔容量一眼不同 |
| 10 | 柜台明确位于前景；暂存后能看懂“放下一个、翻开下一层” |
| 15 | 复杂盘面仍能迅速识别栈顶、目标、未知层和柜台占用 |

每一步提交截图时都必须覆盖这四关。任何一步导致点击热区小于 88×88、背景抢视线或下层泄露种类，均不通过。

## 8. 明确不做

- 真实 3D 模型、相机旋转、动态景深。
- 拖拽、倒计时、金币、体力、底导航、BGM。
- Undo/Hint 英文、豆浆/豆腐/鸡蛋。
- 容量数字 2/4、「放这里」徽章、霓虹选中框。
- 第 1–9 关提前画柜台。
