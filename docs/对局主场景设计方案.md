# 对局主场景 · UI 设计方案（专业版 v2）

对照：`docs/ui_refs/03_play.png`、`docs/ui_refs/09_hint.png`。  
气质跟示意图；**不要抄** Undo/Hint 英文、豆浆/豆腐/鸡蛋、底导航、倒计时、金币。

对 AI：**只做步骤 N**。做完停，等验收再开 N+1。

---

## 1. 目标画面（对齐 `03_play`）

玩家在 0.5 秒内应读出三件事：

- **这是一台“软壳灰蓝冰箱”**：一整台大物体，槽位是壳体挖窗，不是一排独立盒子
- **中间是一排“刚买回来的袋子”**：一组静物放在置物板上，不漂在墙上
- **下面是厚木柜台**：第 10 关起才出现（三盘），1–9 关留白露出台面

## 2. 现在为什么“丑/单调”（对照 `03_play`）

- **冰箱外框太紧**：外框贴槽位 → 像“框住一排格子”，不是“家电”
- **槽位上下空洞**：小容量时把整槽缩短 → 上下留下大片无意义空腔
- **食物区缺组块**：只有方砖叠放 → 没有“提手/落影/置物板”，中层平

## 3. 冰箱改造方案

### 3.1 外框（壳体）

一句话：**加厚加松，让冰箱像一个物体**。

- **宽度**：冰箱整体不要顶满 720；两侧各留 ≥ 36，让 `assets/ui/scene/bg_play.png` 的砧板/绿植露头
- **圆角**：外框圆角约 48（外框 > 内窗），边缘要“软”，不要硬描边 UI
- **壳体厚度**：内窗距外框至少 36–48（决定“松不松”）
- **隔断**：隔断来自壳体本身（宽 16–20），不要每槽再画胡桃外圈

颜色语言（方向，不写死值）：

- 壳体：灰蓝偏暖（比 FridgeGlow 更灰一点）
- 内窗底：更深灰蓝（“挖进去”的洞感）
- 内窗高光：冷白柔光（空槽更亮，放入食材后收弱）

### 3.2 槽位（为步骤 2 预埋设计）

原则：**所有槽位外高一致**；容量差异通过“窗内可用高度”表达，而不是把整槽缩成短棍子。

槽内从上到下的结构（步骤 2 才实现）：

```
顶灯条（空槽更亮）
上填充（cap 小才有：壳体垫块/死空间）
可用内腔（FridgeGlow）
底托（食材坐在底托上）
```

### 3.3 选中态

- **目标格**：2–3px Walnut 描边贴在“内窗沿” + 冷光加强
- **未选中**：不画描边（减少杂线）

## 4. 中层食物区点缀方案（不改玩法）

一句话：**让袋子看起来“搁在置物板上”**。

- **提手**：每列顶部加一弯提手（同列色降低饱和或浅胡桃），高度 24–32，不挡热区
- **落影**：每列底部一片椭圆暖影（低透明），让方砖“压住台面”
- **置物板**：所有列下加一条奶油色圆角板（高 20–28，宽覆盖所有列并左右外扩 24）

## 5. 分步落地（逐步调整，不一口吃完）

- **步骤 1**（先做）：冰箱外框放宽放松 + 隔断归壳体 + 去掉每槽胡桃外圈  
  - **验收**：第一眼像“一个冰箱”；左右露出背景道具；槽位仍一眼可点
- **步骤 2**：槽内顶灯/底托/上填充，让 cap2 不再上下空洞；混容量外框仍齐高
- **步骤 3**：中层提手/落影/置物板，让食物区更有静物感
- **步骤 4**：最后再收一次三层间距（避免挤/散）

## 6. 验收截图清单（每步都用这三关看）

- **第 1 关（单槽/最少元素）**：像不像一台冰箱（有“左右耳朵”，不细条）
- **第 9 关（全 cap2）**：矮槽是否仍然稳定（步骤 2 的重点）
- **第 17 或 18 关（混容量）**：外框齐高是否成立，容量差异是否一眼可读

## 1. 冰箱（先改，决定整屏气质）

### 1.1 壳体

一台黏土家电，不是「一排独立木盒 + 外框」。

- 圆角约 **48**，左右边距约 **40–48**（现在约 24，显得勒）。
- 颜色：壳 `#B0C4D2`，亮面 `#D5E2EA`，内窗 `#9BB3C4`，描边 `#7E98AA` 2–3px。不要再叠 6 层假立体。
- 槽与槽之间是**同一块壳体**（隔断宽 16–20），不要每格再画一圈胡桃。
- 1 格关也要够宽的左右耳，看起来仍是一台冰箱，不是一根管子。
- 宽度不要顶满 720，左右各留 ≥36，让 `bg_play` 的砧板和绿植露头。

### 1.2 槽：上下填充（小容量的关键）

示意图四格**外高相同**。容量不靠整格缩放，靠槽内可用高度。

每个槽从上到下：

```
[顶灯条]     冷白高光，空槽更亮，有食材后收弱
[上填充]     仅 cap < 本关最大格：同色壳体垫块（小格的「死空间」）
[可用内腔]   FridgeGlow，食材从底往上叠
[底托]       浅灰蓝凹槽底，食材坐在上面，不再漂
```

- **cap 4**：几乎没有上填充，四件顶到灯条下。
- **cap 2**：上下各垫约 1 件高的壳体，中间只够两件；一眼看出这格更浅。
- **cap 3**：上垫约半件到 1 件。
- 混容量（17、18 关）：外框仍是齐高的一台冰箱；矮格用上填充区分，**不要**把整格缩成短棍子。
- 不要在格上写 2/4。不要「放这里」徽章。选中 = 槽内冷光加强 + 2–3px 胡桃描边贴在内腔外沿。

### 1.3 封格

仍是该槽灰门合上 + 右侧小把手，门贴在可用内腔里，不是整台冰箱关门。

---

## 2. 食物区（中间层点缀）

袋子已经是色托盘叠，缺的是「这是刚提回来的一打」。

- **提手**：每列顶部一弯黏土提手（同列托盘色，或浅胡桃），高约 28，不挡点栈顶（热区仍是最上一块砖）。
- **落影**：列底一层椭圆暖影，让砖离开墙面。
- **置物板**：所有列底下一条圆角奶油木条（宽随列数，高 20–28），像桌面，把「飘在背景上的砖」收成一组静物。
- 栈顶 100%、下面 60% + 0.92 不变。
- 不要在砖上再写豆浆/豆腐/鸡蛋，不要塑料袋写实。

第 1–9 关没有柜台时，置物板下面仍是厨房台面（`bg_play`），不要补三个空盘。

## 3. 整屏节奏（解决单调）

720×1280，三层中心大致：

```
y  540    HUD（关卡胶囊 + 圆钮）——已有，本方案不重做
y  420    冰箱壳体中心（比现在略上、略松）
y   40    购物袋 + 置物板
y -360    柜台（≥10 关；1–9 关留白露出台面）
```

数字验收时再微移，原则：

1. 冰箱、袋子、柜台是三件**物体**，中间要有空气，不要三层贴死。
2. 背景道具只露边，不新增可点物。
3. 仍然：先选格（不计步），再点食材（计步）。点缀一律不可点、不挡热区。
