## 1. 风格

**Night Fridge（2.5D 暖夜厨房）**

轻俯视厨房：暖墙远景 → 木框冰箱格中景 → 工作台 + 叠盘 → 前景柜台（第 10 关起）。

立体感来自：统一视角、可见顶面、前立面、遮挡、同向投影。禁止多重粗描边、霓虹外发光、悬浮胶囊冒充立体。

| 要 | 不要 |
|----|------|
| 奶油底 + 冷光内腔 | 霓虹、炫光 |
| 哑光黏土食材 | 写实照片菜、描边小人 |
| 一个 Coral 主按钮 | 满屏按钮 |
| 大留白、大热区 | 资源条、倒计时 |
| 失败闪暖 Coral | 爆炸、嘲笑角色 |

0.5 秒内应读出：上方目标冰箱格、中间可点栈顶、下方柜台（若有）、当前目标在哪。

## 3. 字体

系统圆体即可。主标题 56–64 / 关卡 28 / 正文 28 / 主按钮 32 / 辅助 24。行高 1.3。按钮字无描边、无斜体。

胜利步数：数字大号 Coral；「步」字约为数字一半字号。

---

## 4. 画布与 2.5D

- 设计稿 720×1280；内容避开刘海；主按钮距底 ≥48。  
- 热区 ≥88×88；卡片圆角 32；主按钮胶囊。  

坐标：文档用屏幕左上原点；Cocos 中心原点换算：

```text
cocosX = screenX - 360
cocosY = 640 - screenY
```

造型：轻俯三分之四；左上暖光；投影右下 8–16px；接触影必有。  
遮挡顺序：墙 → 冰箱落影 → 冰箱格 → 台面后沿 → 购物袋 → 台面前沿 → 柜台 → HUD。

Graphics 只画状态线/光/简单形；主体用透明 PNG。

## 5. 组件

**主按钮** 高 96、Coral、字 Milk；按下 scale 0.97；全屏同时一个 Coral。  
**次按钮** 同高、Walnut 浅描边、Milk 底；文案「让好友也收这一层」「分享步数」。  
**文字链** 「重开本关」字号 26、Walnut 60%。  
**圆钮** 撤销 / 提示直径 80；中文图标语义，不要 Undo/Hint 英文。

**冰箱格（现行）**  
并列胡桃木圆角木框 + 内腔。所有格外高一致；cap2/3/4 靠内腔可用高度与叠放表达，**不写 2/4 数字**，不把小容量格整体缩矮。收满后该格**灰门合上**（可带小把手），不用珊瑚餐盒盖。

**选中态**  
内腔冷光增强 + 贴窗沿 2–3px Walnut 描边 + 内容略前移约 1.03。禁止珊瑚粗框、「放这里」徽章。柜台目标同语言。

**购物袋**  
一列一叠托盘。栈顶完整食材；下层中性奶油边 + 层数刻痕。翻层约 180ms。不要写实塑料袋，不要下层染色。

**柜台**  
第 10 关起：胡桃木前景板 + 3 个 Milk 凹槽，比购物袋更靠前、投影更强。1–9 完全不实例化。

### 5.1 状态语言

| 状态 | 视觉 | 禁止 |
|------|------|------|
| 可点栈顶 | 完整食材 + 接触影 | 常驻外发光 |
| 未知下层 | 中性边 + 层数 | 泄露种类色/轮廓 |
| 当前目标 | 冷光 + 细窗沿 + 微前移 | 粗珊瑚框 |
| 提示 | Sage 虚线同时圈格与食材 | 只圈一个 |
| `buffer_full` | 柜台 Coral 闪 | 锁错也闪柜台 |
| `locked_out` | 锁错格内腔 Coral 闪 | 假装柜台满 |

## 6. 界面结构

### 6.1 主页（可后做精致）

- 标题「今晚冰箱」；主按钮「开始收拾」→ 已通最高关+1  
- 文字链「我收过的冰箱 n/30」→ 图鉴  
- 设置仅音效/震动；无商城、无音乐开关  

### 6.2 对局

四个纵深面（屏幕左上坐标参考）：

```
y  88–164    HUD：第 N 关 / 撤销 / 提示
y 178–520    冰箱木框格
y 548–920    工作台顶 + 购物袋 2–6 列
y 850–960    工作台前立面
y 930–1168   前景柜台（第 10 关起）
```

- 无倒计时、无金币、无暂停大金钮；暂停进关卡号点击。  
- 飞入约 220ms；弹回 80ms + Toast 1.2s；翻层 180ms。  

### 6.3 胜利结算

全屏灰色蒙版（约 40% 压暗）。  

- 顶部标题图：`assets/ui/fx/win_perfect.png`（「完美收纳！」+ 副文案），**按原图像素等比缩放，禁止压扁**  
- 奶油卡居中：小奖杯冰箱示意、「今晚冰箱收好了」、大号步数（「步」半号）、主按钮「下一关 >」、次按钮「分享步数」、章「图鉴 +1」  
- 不要底导航、烟花、金币雨  

### 6.4 失败结算

卡片**屏幕居中**。对局仍可见，勿挡死出错层。

| 类型 | 标题 | 主按钮 |
|------|------|--------|
| `buffer_full` | 柜台堆满了 | 多一格继玩 |
| `locked_out` | 这格锁错了 | 退回可收的一步 |

共用：次按钮「让好友也收这一层」；文字链「重开本关」。无星星、倒计时。

### 6.5 图鉴 / 暂停 / 提示

- 图鉴：我收过的冰箱；3 列成品缩略；再收一次；无相册 Tab、无底栏开始。  
- 暂停：继续 / 重开 / 回主页。  
- 提示：双高亮；无「剩余提示 n/n」。第 7 关首次免费。  

### 6.6 教学态

- 第 4/7：选中描边 + 弹回 Toast「换一格」+ 闪合法格。  
- 第 8：靠空间高低辨容量，禁止数字标签代替。  
- 第 10：暂存 → 下一层上浮，镜头不切、不弹大模态。

## 7. 动效

| 事件 | 时长 | 做什么 |
|------|------|--------|
| 飞入 | 220ms | 微上拱，盖台面、低于 HUD |
| 翻层 | 180ms | 上浮后显食材；列锁点击 |
| 封格 | 280ms | 灰门 + 短震 |
| 胜利 | 门合后 | 蒙版 → 标题图 → 奶油卡 → 步数 → 按钮 |
| 弹回 | 80ms+1.2s | 横摆 + 分因 Toast |
| 失败前 | 400ms | 按 failReason 闪对应区再出卡 |
