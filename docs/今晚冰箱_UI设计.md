## 1. 风格

**Night Fridge（2.5D 暖夜厨房）**

轻俯视厨房：暖墙远景 → 木框冰箱格中景 → 工作台 + 叠盘 → 前景柜台（第 10 关起）。

立体感来自：统一视角、可见顶面、前立面、遮挡、同向投影。禁止多重粗描边、霓虹外发光、悬浮胶囊冒充立体。

| 要 | 不要 |
|----|------|
| 奶油底 + 冷光内腔 | 霓虹、炫光 |
| 哑光黏土食材 | 写实照片菜、描边小人 |
| 一个 Coral 主按钮 | 满屏按钮 |
| 大留白、大热区 | 资源条、倒计时 |
| 失败闪暖 Coral | 爆炸、嘲笑角色 |

0.5 秒内应读出：上方目标冰箱格、中间可点栈顶、下方柜台（若有）、当前目标在哪。

## 4. 画布与 2.5D

- 设计稿 720×1280；内容避开刘海；主按钮距底 ≥48。  
- 热区 ≥88×88；卡片圆角 32；主按钮胶囊。  

坐标：文档用屏幕左上原点；Cocos 中心原点换算：

```text
cocosX = screenX - 360
cocosY = 640 - screenY
```

造型：轻俯三分之四；左上暖光；投影右下 8–16px；接触影必有。  
遮挡顺序：墙 → 冰箱落影 → 冰箱格 → 台面后沿 → 购物袋 → 台面前沿 → 柜台 → HUD。

Graphics 只画状态线/光/简单形；主体用透明 PNG。

## 5. 组件

**主按钮** 高 96、Coral、字 Milk；按下 scale 0.97；全屏同时一个 Coral。  
**次按钮** 同高、Walnut 浅描边、Milk 底；文案「让好友也收这一层」「分享步数」。  
**文字链** 「重开本关」字号 26、Walnut 60%。  
**圆钮** 撤销 / 提示直径 80；中文图标语义，不要 Undo/Hint 英文。

**冰箱格（现行）**  
并列胡桃木圆角木框 + 内腔。所有格外高一致；cap2/3/4 靠内腔可用高度与叠放表达，**不写 2/4 数字**，不把小容量格整体缩矮。收满后该格**灰门合上**（可带小把手），不用珊瑚餐盒盖。

**5 格冰箱（B0，已被 B1 部分取代）**  
`n >= 5` 且**非混容量**时仍走 B0：`scale` 大/中/小 = 1.0 / 0.85 / 0.70，基准外宽 132、外高 300，`gap = 10`。  
`n >= 5` 且**混容量**（如第 26 关）→ **§11 B1**（窄/中/宽+双层、统一外高 300）。`n ≤ 4` 仍用原 `trayMetrics`，1–18 关外观不变。

**选中态**  
内腔冷光增强 + 贴窗沿 2–3px Walnut 描边 + 内容略前移约 1.03。禁止珊瑚粗框、「放这里」徽章。柜台目标同语言。

**购物袋**  
一列一叠托盘。栈顶完整食材；下层中性奶油边 + 层数刻痕。翻层约 180ms。不要写实塑料袋，不要下层染色。

**多列折成两排（≥5 列）**  
- **触发：** `bags.length >= 5` 才折两排；4 列及以下保持一排（前半程教学构图不变）。  
- **深后浅前：** 按**开局**各列深度（`level.bags[i].length`）从高到低排序；后排（靠冰箱下沿）放最深的 `⌈n/2⌉` 列，前排（靠柜台）放其余较浅列。同深按原列号稳序。  
- **整关锁排：** 开局定前后排后，翻层/变矮**不换排**，避免盘面跳动。  
- **缩放：** 后排约 0.92，前排 1.0；每排按「该排列数」算 `bagLayout`（勿用总列数去缩），保证 5–6 列时单盘仍可读。  
- **纵距：** 后排座面高于前排；后排柱顶与冰箱格底边留白 ≥24；前排不压柜台凹槽。  
- **绘制顺序：** 先画后排再画前排，保证前排可点、不被后排误挡。  
- **禁止：** 前排放最高柱；后排不可点；中途按当前深度重排。

**柜台**  
第 10 关起：胡桃木前景板 + 3 个 Milk 凹槽，比购物袋更靠前、投影更强。1–9 完全不实例化。

### 5.1 状态语言

| 状态 | 视觉 | 禁止 |
|------|------|------|
| 可点栈顶 | 完整食材 + 接触影 | 常驻外发光 |
| 未知下层 | 中性边 + 层数 | 泄露种类色/轮廓 |
| 当前目标 | 冷光 + 细窗沿 + 微前移 | 粗珊瑚框 |
| 提示 | Sage 虚线同时圈格与食材 | 只圈一个 |
| `buffer_full` | 柜台 Coral 闪 | 锁错也闪柜台 |
| `locked_out` | 锁错格内腔 Coral 闪 | 假装柜台满 |

## 6. 界面结构

### 6.1 主页（可后做精致）

- 标题「今晚冰箱」；主按钮「开始收拾」→ 已通最高关+1  
- 文字链「我收过的冰箱 n/30」→ 图鉴；`n` 到 10/20/30 首次达成弹**里程碑分享卡**（Sage 底 + 缩略拼图 + 「今晚已收 N 关」，主按钮「叫朋友一起收」，次链「先不用」，不阻塞返回）；同阈值只弹一次，写 `album.milestone10/20/30 = true`  
- 设置仅音效/震动；无商城、无音乐开关  

### 6.2 对局

四个纵深面（屏幕左上坐标参考）：

```
y  88–164    HUD：第 N 关 / 撤销 / 提示
y 178–520    冰箱木框格
y 548–920    工作台顶 + 购物袋（≤4 列一排；≥5 列两排，深栈后排贴冰箱）
y 850–960    工作台前立面
y 930–1168   前景柜台（第 10 关起）
```

- 无倒计时、无金币、无暂停大金钮；暂停进关卡号点击。  
- 飞入约 220ms；弹回 80ms + Toast 1.2s；翻层 180ms。  

### 6.3 胜利结算

全屏灰色蒙版（约 40% 压暗）。  

- 顶部标题图：`assets/ui/fx/win_perfect.png`（「完美收纳！」+ 副文案），**按原图像素等比缩放，禁止压扁**  
- 奶油卡居中：小奖杯冰箱示意、「今晚冰箱收好了」、大号步数（「步」半号）、主按钮「下一关 >」、次按钮「分享步数」、章「图鉴 +1」  
- 不要底导航、烟花、金币雨  

### 6.4 失败结算

卡片**屏幕居中**。对局仍可见，勿挡死出错层。

| 类型 | 标题 | 主按钮 |
|------|------|--------|
| `buffer_full` | 柜台堆满了 | 多一格继玩 |
| `locked_out` | 这格锁错了 | 退回可收的一步 |

共用：次按钮「让好友也收这一层」；文字链「重开本关」。无星星、倒计时。

**软化拉新**：同一关连续失败 ≥3 次时（`sessionFailStreak[level] ≥ 3`），本次失败卡在标题下加一行 Walnut 24 副文案「今晚这层老过不去，喊 TA 一起收」；不改按钮、不改结构；胜利即清零。

### 6.5 图鉴 / 暂停 / 提示

- 图鉴：我收过的冰箱；3 列成品缩略；再收一次；无相册 Tab、无底栏开始。顶部一行 `n / 30` 收纳进度；已收单卡**长按 260ms** 触发系统分享（22 / 25 / 30 三关的成品图作为常备分享素材，其他关允许但不做引导）。  
- 暂停：继续 / 重开 / 回主页。  
- 提示：双高亮；无「剩余提示 n/n」。第 7 关首次免费。  

### 6.6 教学态

- 第 4/7：选中描边 + 弹回 Toast「换一格」+ 闪合法格。  
- 第 8：靠空间高低辨容量，禁止数字标签代替。  
- 第 10：暂存 → 下一层上浮，镜头不切、不弹大模态。

## 11. 对局辨色与混宽格（B1）

**适用：** 对局中间层视觉；还原基准 **第 26 关**（五格 cap `2,3,3,3,4`，总位数 15；六列深袋 + 柜台）。  
**不含：** 关卡件数、通关规则、数值表。  
**坐标：** 720×1280，**屏幕左上原点**；Cocos 换算见 §4。

### 11.1 上方存储柜（替代五等宽竖条）

**原则**

| 项 | 说明 |
|----|------|
| 逻辑 | 仍为 **5 个可点冰箱格**，索引 0→4 从左到右；每格 `cap` 只读关卡数据 |
| 容量 | 五格总收纳位数与关卡一致（L26 = **15**）；只改外轮廓与内腔层次 |
| 对齐 | **顶边、底边共线**（统一外高）；横向一条木框基线 |
| 宽度 | 按 `cap` 映射 **窄 N / 中 M / 宽 W（双层）**，禁止五格等宽 |

**格型尺寸（外框含木边，px）**

| 格型 | cap | 外宽 W | 外高 H | 木框 F | 内腔宽 | 内腔高 | 视觉 |
|------|-----|--------|--------|--------|--------|--------|------|
| **N 窄** | 2 | 100 | 300 | 14 | 72 | 272 | 单腔；底弱高光圆（状态保留） |
| **M 中** | 3 | 128 | 300 | 14 | 100 | 272 | 单腔；**2 条水平浅槽线**（装饰，非数字） |
| **W 宽** | 4 | 168 | 300 | 14 | 140 | 272 | **双层**：正中水平木隔板高 6px；上腔 128 / 下腔 138；下腔明度比上腔低约 5% |

**间距与排布**

- 格间距 **G = 8**（五格时）。  
- 总宽 = 100 + 128×3 + 168 + 8×4 = **684**，水平居中：首格外框左缘 **x = 18**。  
- 外框顶 **y = 220**，外框底 **y = 520**（与 §6.2 冰箱区 y178–520 兼容）。

**L26 从左到右（cap 序 2,3,3,3,4）示意**

```text
    ┌──┐ ┌────┐ ┌────┐ ┌────┐ ┌──────────┐
    │窄│ │ 中 │ │ 中 │ │ 中 │ │ 上│下 宽 │
    │2 │ │ 3  │ │ 3  │ │ 3  │ │ 4  双层│
    └──┘ └────┘ └────┘ └────┘ └──────────┘
    ═══════════════════════════════════  木框底梁 y=520
```

**程序映射（按 cap，勿按索引写死）**

```text
cap === 2  →  N, 外宽 100
cap === 3  →  M, 外宽 128
cap === 4  →  W, 外宽 168（双层内腔）
其它       →  就近：1→N，5→W
```

### 11.2 容器 vs 物品辨色

**分层**

| 层级 | 角色 | 要求 |
|------|------|------|
| A 木框 | 容器结构 | 低饱和、中低明度 |
| B 内腔 | 承载面 | 冷灰蓝、低饱和；禁止暖黄/奶油作主底 |
| C 叠盘 | 操作台临时容器 | 中性暖灰褐；禁止与 lemon/fruit 同色相 |
| D 食材 | 可识别物 | 明度高于 B/C；饱和度更高；必有接触影 |

**HEX（B1 增补 Token）**

| Token | Hex | 用途 |
|-------|-----|------|
| CabinetFrame | `#8F6B52` | 冰箱木框、隔板、把手 |
| CabinetCavity | `#C9D8DE` | 内腔底（未选中） |
| CabinetCavitySel | `#E2EEF2` | 选中内腔 |
| CounterTray | `#D4C4B0` | 操作台叠盘顶面、前唇 |
| CounterTrayLip | `#EBE2D6` | 叠盘前唇高光 |
| CounterSlotShadow | `#3D3229` @ 18% | 盘下接触影 |
| MilkBoxBody | `#F7FAFC` | 牛奶盒主体 |
| MilkBoxLabel | `#5B7C9A` | 牛奶标贴/蓝条 |
| CitrusBody | `#F08C2E` | 橘子/柠檬果肉主色 |
| CitrusHighlight | `#FFD89A` | 柑橘高光 |
| CitrusLeaf | `#6F9B5C` | 叶/蒂 |

§2 既有 Cream / FridgeGlow / Frame 等仍用于 HUD、主页、按钮；**对局内腔与叠盘**以本表为准，冲突时 **B1 优先**。

**自检（美术 + 程序）**

1. 食材主色与承载面 **HSB 色相 H 差 ≥ 25°**（尤其 citrus vs 黄盘）。  
2. 食材主体 **L\* 比承载面高 ≥ 18**（牛奶 vs 内腔、柑橘 vs CounterTray）。  
3. 袋**下层**仍中性盘 + 层数，不泄露种类色（§0 不变）。  
4. 选中：仅 CabinetCavitySel + **2px `#6B4A3A` 窗沿** + scale≈1.06；禁 Coral 粗框（§5 不变）。

### 11.3 中间操作台叠盘错落

**区域不动：** §6.2 y548–920；**≥5 列两排**规则不变（深后浅前、后排 0.92、前排 1.0、开局锁排、先画后排）。

**三档盘径（在 `bagLayout` 基准 w 上）**

| 档位 | 系数 | 适用列 |
|------|------|--------|
| L | 1.00× | 该排深度最大列 |
| M | 0.89× | 中等深度 |
| S | 0.81× | 浅列（如单颗柠檬列） |

宽 w 取整为**偶数 px**；单盘热区仍 **≥88×88**，跟节点走。

**列级偏移（整关固定，翻层不改）**

以列几何中心为基准，只改绘制（点击跟节点）：
